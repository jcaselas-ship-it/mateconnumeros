# ♚ Mate en números

Juego de ajedrez para la **Escuela Técnica de Ajedrez (ETX)**: las negras están en jaque mate, pero todas las piezas son números. Cada número es un tipo de pieza (mismo número = misma pieza) y hay que averiguar cuál es cada una.

- 17 mates clásicos: del pasillo, árabe, Anastasia, Boden, Blackburne y muchos más.
- **Modo Retos:** los retos se van desbloqueando y dan puntos.
- **Modo Libre:** practicar cualquier reto, sin puntos.
- Pistas, botón para rendirse, explicación de cada mate y modo difícil (puntos ×2).
- Varios tableros y sets de piezas, modo oscuro y progreso guardado en el dispositivo.
- **PWA:** se puede instalar en el móvil o el ordenador y funciona sin conexión.

Para jugar, abre la página publicada en GitHub Pages y, si quieres, pulsa «Instalar» o «Añadir a pantalla de inicio».

> Al subir cambios, sube también la versión de `CACHE` en `sw.js` (`mateconnumeros-v2`, `-v3`…).
